## 1. 방법 · 범위 · 한계

- **빌드**: `web/index.html`은 소스와 같은 커밋(`ba31eb3`)에서 만든 것이라 다시 빌드하지 않았어요.
- **흉내 서버** (8980~8982만 사용, 끝나고 `fuser -k`로 정리): `qa/news/mock_api.py 8980`(히트맵 · 뉴스 · 오늘 공시 · `/api/live` off), `qa/world/mock_api.py 8981` + `/__mode?macro=on`(해외 · 지표 + 환율 · 금리), `qa/stock/mock_api.py --port 8982`(종목 페이지). 종목 흉내 서버는 `iv=`를 몰라서 Playwright에서 `chart?iv=day` → `tf=1y`로 바꿔 보냈어요. d3 · lightweight-charts · Pretendard CDN은 에이전트 프록시로 받았어요.
- **화면**: 390 × 844(`is_mobile`, `has_touch`, DPR 2) · 1440 × 900(DPR 1), 테마 `khm.theme` = `base · paper · glass-dark · glass-light`(JSON 문자열), 나머지 `khm.*`는 비운 상태(기본값). 측정 시각은 **일요일 16:3x KST → 휴장 상태**라 장중에만 보이는 것(실시간 점 맥동, NXT 배지, 동시호가 테두리)은 화면에 없어요.
- **정적 분석**: `src/template.html`의 `<style>`(29~1202줄)과 모듈 CSS 6개를 직접 파싱해 선언 8,376개를 셌어요(template 3,235 · stock 1,676 · extras 1,368 · world 1,320 · news 412 · disc 325 · live 40). JS의 인라인 색 · 폰트 · WAAPI 길이는 grep.
- **렌더 측정**: 화면마다 보이는 모든 `button · a · [role=tab|switch] · input`을 부모 + 클래스로 묶어 높이 · 모서리 · 글자 · 안쪽 여백 · 바탕 · 그림자 · 전환 길이를 모았어요. 글자는 보이는 텍스트 노드마다 계산된 글자색 × 조상 opacity를 조상 배경(반투명은 합성)에 올려 WCAG 2.x 비율을 냈어요.
- **한계**: 그라데이션 배경(글라스)은 바탕색만 계산 — 위쪽 반사광 때문에 실제로는 조금 더 낮을 수 있어요. 지도 타일 · 캔버스(차트) · SVG 안 글자는 대비 계산에서 뺐어요. `color(srgb …)`(color-mix 결과) 배경은 자동 스캔이 못 읽어 §5에서 손으로 계산했어요. 실기기 · Safari 확인 없음.
