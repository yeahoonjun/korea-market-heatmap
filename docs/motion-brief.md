# 모션 브리프 — `효과: 화려하게` (fancy)

AGENTS.md §3-5의 새 효과를 구현할 때 따르는 값이에요. `KH.motion()`이 `'fancy'`일 때만 적용하고, `'standard'`는 지금 동작 그대로, `'reduced'`는 모든 전환을 끄고 최종 상태를 바로 그려요. 색 규칙(§4: 빨강·초록 = 데이터, 앰버 `#ffb547` = UI)은 효과에서도 그대로예요.
조사 2026-11-10: 쇼룸 HTML의 CSS·JS를 직접 읽고 Playwright로 렌더, 사이트는 Playwright로 `getAnimations()`·스타일시트 easing·hover 시간 측정, X 글은 공식 oEmbed로 읽음.

## 1. 레퍼런스 공통점

- **짧은 3단 시간표 + 감속 곡선 하나.** 쇼룸은 `--dur-1/2/3 = .12/.24/.48s`, `--ease-out: cubic-bezier(.2,.7,.2,1)`, `--ease-in-out: (.6,0,.2,1)`을 CSS 변수로 두고 JS가 같은 값을 읽어 써요. reui·aerive·heydamir도 `(.22,1,.36,1)` 한 계열에 .15s/.6s 정도, coss·bklit 팝오버는 150ms `(.4,0,.2,1)`. 튀어 오르는(overshoot) 곡선은 거의 안 써요.
- **움직임은 transform·opacity에만.** 등장은 "opacity 0 + 8~18px 위로 + scale .96~.985" 한 가지(쇼룸 `rise`·`ch-sheet-in`, coss `scale-98`, heydamir `appear`, aerive `dialog-in`). hover·press는 임계 감쇠 스프링(쇼룸 `stiffness 420, damping 32, mass .6`, scale 1.02 / press .97→1).
- **숫자를 크게, 보조 정보는 작게.** 쇼룸 `.stat-v`(굵기 650, 자간 −0.05em, 행간 .95, 0.6초 카운트업), aerive 큰 "01:17 AM" 현지 시각, Shopify Editions 큰 장 제목과 작은 고정폭 색인. 숫자는 모두 tabular.
- **실시간 데이터는 "신호"로만 움직여요.** bklit 라이브 라인(`lerpSpeed .08`, 맥동 점, 값 배지), 히트맵 셀 열 단위 등장(1.1초 물결, 셀당 450ms), hover 때 나머지 0.3으로 흐림, 툴팁은 스프링으로 셀 사이를 따라가고 `hideDelay 120ms`. Shopify의 "Updated 12s ago" 카드.
- **필요할 때만 그려요.** 쇼룸 WebGL은 바뀌는 게 있을 때만 rAF, IntersectionObserver(여백 80px)·`visibilitychange`로 멈춤, DPR ≤ 1.5, 폭 720 미만이거나 터치+4코어 이하면 저사양 단계. Lenis도 스크롤 중에만 rAF.
- **질감은 아주 옅게.** aerive 전체 화면 필름 그레인 불투명도 .045(SVG `feTurbulence` 0.85·2옥타브), 쇼룸 셰이더는 ±0.5/255 디더로 띠무늬 제거, grainient는 그레인 그라데이션을 배경 자산으로만 써요.

## 2. 화려하게 모션 시스템

### 2-0. 토큰 (template.html `:root`에 두고 JS는 `getComputedStyle`로 읽어 한 곳에서 관리)
```css
--m-1:120ms; --m-2:240ms; --m-3:480ms;      /* 쇼룸 dur-1/2/3 */
--m-flash:700ms; --m-roll:420ms; --m-fly:700ms; --m-stagger:40ms;   /* stagger = m-1/3 */
--m-out:cubic-bezier(.2,.7,.2,1);    /* 기본 등장·이동 (지금 FLIP과 같은 곡선) */
--m-quint:cubic-bezier(.22,1,.36,1); /* 숫자 착지·작은 글자 등장 */
--m-inout:cubic-bezier(.6,0,.2,1);   /* 모양이 바뀌는 전환: 보기 전환, 공유 요소 */
--m-exit:cubic-bezier(.4,0,.2,1);    /* 사라짐·팝오버 */
--m-fly-ease:cubic-bezier(.83,0,.17,1); /* 카메라 비행 (bklit zoomTransition) */
```
- 사라짐은 등장보다 짧게(`--m-1` + `--m-exit`). overshoot 금지(값보다 커 보이는 순간이 생겨요). 스프링은 ζ≈1(k 420, c 32, m .6 → 약 250ms, 튐 없음)만 쓰고, 바닐라 JS에선 `--m-2 --m-out` 또는 지수 추종 `x += (t−x)·(1−e^(−dt/τ))`로 근사(τ 70ms: 카메라·툴팁 따라가기).
- 진행 중인 애니메이션은 `kh:motion`이 `fancy`에서 내려가면 `anim.finish()`로 끝 상태로 보내요.

### (a) 시세 플래시 — 지도 타일, 표
- 조건: `kh:data`에서 `p`가 이전 값과 다른 종목, 첫 그림·리플레이 중 제외. 방향은 **직전 값 대비**(틱 방향)이고 하루 등락 부호와 무관.
- 타일: 채움색은 그대로, `::after`에 고리를 미리 칠해 두고 **opacity만** 움직여요. `box-shadow: inset 0 0 0 2px var(--up-text), inset 0 0 14px color-mix(in srgb, var(--up-text) 45%, transparent)`(하락은 `--dn-text`). 키프레임 `0% 0 → 12% 1 → 100% 0`, `--m-flash`, `--m-out`. 짧은 변이 24px 미만이면 1px 고리만, 안쪽 빛 없음. 지금의 흰/검정 덮개 플래시는 `standard`에 남겨요.
- 동시에 최대 60개: 넘치면 `|Δp/p| × 타일 면적` 큰 순. 같은 틱에 다 함께 깜박이지 않게 코드 해시로 0~200ms 지연(체결 테이프 느낌). 같은 타일이 700ms 안에 또 바뀌면 이전 애니메이션 취소 후 다시.
- 표: 현재가·등락률 칸 배경 `color-mix(in srgb, var(--up-text) 22%, transparent)` → 투명, 같은 키프레임. 화면에 보이는 행만.
- 3D 보기: 같은 규칙으로 윗면 밝기 펄스(아래 f).

### (b) 숫자 롤링 (오도미터) — 시장 띠, 종목 페이지 현재가, 리플레이 시각
- 구조: 자릿수마다 `<span class=d>`(높이 1em, `overflow:hidden`, `mask-image: linear-gradient(transparent, #000 18%, #000 82%, transparent)`) 안에 0–9를 두 벌(20줄) 세운 열, `translateY(-n em)`. 쉼표·점·부호·단위는 고정 글자. 바깥 요소에 `aria-label`=전체 값, 열은 `aria-hidden`.
- 바뀐 자리만 굴려요. 값이 오르면 아래에서 위로(a→b, b<a면 a→b+10), 내리면 반대(b>a면 a+10→b), 끝나면 애니메이션 없이 b로 맞춤. `--m-roll`, `--m-quint`, 오른쪽 자리부터 30ms씩 늦게(최대 120ms).
- 자릿수·부호가 바뀌면(9,990→10,010) 굴리지 말고 숫자 전체를 `--m-1` 교차 페이드. 이미 등락색인 숫자는 색 그대로, 색이 없는 숫자만 바뀐 자리를 700ms 동안 `--up-text`/`--dn-text`로 물들였다 돌려요.
- 시장 띠(흐르는 티커): 화면에 보이는 항목만 굴리고(IntersectionObserver), 나머지는 즉시 교체. 지도 타일 라벨에는 쓰지 않아요(개수가 많고 플래시가 이미 신호예요).

### (c) 첫 진입 연출 + 머리글 카운트업
- 세션당 한 번(`sessionStorage`), 지도 보기에서 데이터가 있는 첫 렌더에만. 어떤 입력(pointerdown·keydown·wheel)이든 들어오면 즉시 `finish()`.
- 섹터 순서(그려진 순서 = 시총 큰 섹터부터)로 섹터 지연 `i × min(40, 400/섹터 수)`ms, 섹터 안은 시총 순위 × 6ms(최대 80ms). 타일 키프레임 `opacity 0, scale(.94)` → 끝, 220ms `--m-out`, 원점은 타일 가운데. 섹터·업종 머리글은 그 섹터 시작 때 opacity만 `--m-2`. 총 700ms 이내.
- 구현: 렌더 때 타일마다 `--dl` 하나만 쓰고 `.fx-intro .tile{animation: fx-in 220ms var(--m-out) var(--dl) both}`. 끝나면 클래스 제거. 연출 중인 타일은 FLIP하지 않아요.
- 머리글 지수: **전일 종가(value−change) → 현재값**으로 600ms(`--m-3`+`--m-1`) `--m-out` 카운트업 — 0부터 세지 않아요(오늘 방향이 보이게). 대비·등락률은 0에서. 색은 처음부터 최종 색.

### (d) 타임랩스 리플레이
- 프레임 간격 `1000/speed`ms(1×·2×·4×). 재생 중 트윈 = 간격 × 0.9, **easing `linear`**(프레임마다 감속하면 매번 멈칫해요). 0.9라서 다음 FLIP 전에 이전 FLIP이 끝나 튀지 않아요. 한 칸 이동·슬라이더 놓기는 `--m-3 --m-out`, 슬라이더 끄는 중엔 즉시.
- 크기: 프레임마다 FLIP 한 번(기간 = 트윈). 색: `d3.interpolateLab`으로 30Hz 이하, 변화 없는 타일은 건너뜀. % 글자: 10Hz로 반올림 값 갱신(타일마다 오도미터 없음).
- 큰 시각 표시: 지도 왼쪽 아래 모서리(플레이어가 덮으면 `--rp-h`만큼 위), `pointer-events:none`. Pretendard 700, `font-size: clamp(48px, 8vw, 128px)`, `letter-spacing:-.05em`, `line-height:.9`, tabular, `color: rgba(255,255,255,.2)`, `text-shadow: 0 1px 0 rgba(0,0,0,.25)`. 위에 작은 줄(12px, 600, `rgba(255,255,255,.55)`): "11월 7일 금요일 · 2배속"(영문·대문자 장식 없음). 휴대폰 44px, 작은 줄 숨김.
- 분이 바뀌면 그 자리를 오도미터로(`min(240, 간격×0.8)`ms). 포인터가 표시 영역(+24px) 안에 오면 `--m-1` 동안 불투명도 .06으로 — 아래 타일을 가리지 않게. 마지막 프레임에서 작은 줄을 "장 마감"으로.

### (e) 세계지도 — 낮/밤 경계, 열린 시장
- 태양 직하점: `d = (Date.now()/864e5) − 10957.5`, `g = 357.529+0.98560028d`, `q = 280.459+0.98564736d`, `L = q+1.915 sin g+0.020 sin 2g`, `ε = 23.439−3.6e-7 d`, `RA = atan2(cos ε sin L, cos L)`, `dec = asin(sin ε sin L)`, `EqT(시) = (q−RA)/15`(±12로 정규화), `lon = −15·(UTC시 − 12 + EqT)`. 밤 중심 = `[lon+180, −dec]`.
- 그리기: `d3.geoCircle().center(밤 중심).radius(r)` 네 겹(r = 90·84·78·72 = 일몰·시민·항해·천문 박명), 각각 `fill:#050814; fill-opacity:.12` → 가장 어두운 곳 약 40%(나라 색이 계속 읽혀요). 경계에 `rgba(255,255,255,.08)` 1px 선 하나. 층 순서: 나라 채움 → 밤 → 국경선 → 열린 시장 빛 → 마커 → 라벨. 1분마다 다시 계산(움직임이 0.25°라 트윈 불필요). `fancy`면 지도를 처음 열 때 나라 → 밤(`--m-3`) → 마커 순으로 페이드.
- 열린 나라: 윤곽 1.25px 앰버 α .6 + 같은 경로를 4px 앰버 α .18·`blur(2px)`로 한 번 깔기(정적, 상태 바뀔 때만 다시). 마커: 5px 앰버 점, 닫힌 시장은 속 빈 회색 점.
- 맥동(`fancy`만): 열린 마커마다 고리 하나 `scale 1→3, opacity .55→0`, 2.4s `--m-out` 반복, `animation-delay = (lon+180)/360 × 2.4s`라 서→동으로 물결. 방금 열린 시장(상태가 OPEN으로 바뀜)은 0.8s 간격 3번 먼저. 숨은 탭·화면 밖이면 `animation-play-state:paused`.
- 등락색 바뀜은 `fill` 480ms 전환(약 40개라 괜찮아요). 나라 hover 때 나머지 `opacity .55`(bklit `fadedOpacity` 참고), `--m-1`.

### (f) 3D 지도 (WebGL, 따로 켜는 보기)
- 카메라: 원근 FOV 26°(쇼룸 22°처럼 좁게 — 크기 비교가 덜 왜곡돼요). 시작 자세: 천정에서 32° 기울임, 방위 −18°. 기울기 0~60°, 방위 ±45°로 제한(라벨이 뒤집히지 않게). 목표값을 τ 70ms 지수 추종(쇼룸 `1−exp(−dt/70)`), 손을 떼면 `fancy`만 각속도 관성 τ 250ms. 확대는 화면 맞춤 거리의 0.6~3배, τ 90ms. 섹터 더블클릭/탭 → 그 섹터로 비행 `--m-fly --m-fly-ease`, Esc·빈 곳 더블클릭 → 복귀.
- 제스처(쇼룸 방식): 가로로 6px 넘고 세로의 1.2배 넘게 끌면 회전 잠금, 터치에서 세로로 10px 먼저 움직이면 페이지 스크롤에 양보(`touch-action: pan-y`). 두 손가락 = 확대·회전. 키보드 ←→ 방위 10°, ↑↓ 기울기, +/− 확대, 0 초기화. canvas `tabindex=0`, `role=img`, `aria-label`.
- 형상: `InstancedMesh` 하나(바닥이 y=0인 단위 상자). 가로·세로 = 타일 w·h − 1px 틈, 섹터 사이 틈 3배. 높이 = `H × min(1, |r|/범위)^0.75`, `H = 0.18 × min(지도 폭, 높이)` — 빌딩 숲이 아니라 지형처럼. **오른 종목도 내린 종목도 위로** 세우고 방향은 색으로만: 아래로 꺼지게 하면 기울인 시점에서 이웃 상자·바닥에 가려 비교가 안 돼요. 0%는 2단위 얇은 판.
- 재질: 그림자·반사·안개 없음. 셰이더에서 **윗면은 팔레트 색 그대로(조명 없음, 범례와 같은 색)**, 옆면은 색 × .78(밝은 쪽)/.62(어두운 쪽) + 아래쪽 15% 어둡게(`mix(.85,1,smoothstep(0,.4,localY))`) 가짜 AO. 섹터 바닥판 `#0d0e11`, 가장자리는 검정으로 페이드(쇼룸처럼 uv 0~0.085), 출력에 ±0.5/255 디더.
- 라벨: WebGL이 아니라 HTML 겹층. 섹터 이름은 바닥 왼쪽 위에 고정, 종목 이름은 윗면이 화면에서 40×18px 넘는 것만 최대 40개(2D와 같은 글자 그림자). 카메라가 움직일 때만 다시 투영.
- hover: rAF로 줄인 raycast, 해당 상자 윗면 +12% 밝기 + 흰 1.5px 윤곽(2D hover와 같은 말투), 다른 상자는 흐리지 않아요. 툴팁은 2D `.tip`을 τ 70ms로 따라가게. 누름은 이동 6px 미만일 때만 `KHStock.open(code)`.
- 등장(`fancy`): **위에서 내려다본 자세(2D 지도와 똑같은 화면)에서 시작** → 32°로 기울이며(700ms `--m-fly-ease`) 상자가 섹터 순서로 솟아요(높이 0→값, 섹터마다 40ms, 각 `--m-3 --m-out`). 1.1초 이내. 2D로 돌아갈 땐 360ms에 거꾸로 접고 `#map`을 보여 줘요. `standard`·`reduced`는 최종 자세를 바로.
- 갱신: 높이·색 `--m-3 --m-out` 트윈(인스턴스 속성 버퍼를 트윈 동안만 매 프레임 올림), 틱 플래시 = 윗면 밝기 펄스 700ms(최대 60).
- 성능: 렌더는 요청 때만(카메라·트윈·hover 변화가 있을 때), 화면 밖·숨은 탭이면 멈춤, DPR `min(dpr,1.5)`(저사양 1.25), 안티앨리어싱은 고사양만. 저사양 = 폭 < 720 또는 (`pointer:coarse` && `hardwareConcurrency ≤ 4`). `KH3D.stats()`로 최근 60프레임 렌더 시간 노출.

### (g) 작은 상호작용
- 타일: hover 흰 고리를 `--m-1`로 페이드(지금은 즉시). 누름 `scale(.985)` `--m-1`, 놓으면 `--m-2 --m-out`(짧은 변 40px 이상만).
- 버튼·칩·분할 버튼: 누름 `.97→1` `--m-2 --m-out`, hover 배경 `--m-1`. 분할 버튼(지도·3D·표, 기본·화려하게, 1×·2×·4×, 목록·지도)과 시장 탭의 활성 표시는 칸 사이를 미끄러져요(`translateX` + `scaleX`, `--m-2 --m-out`).
- 시장 탭 바꿈: 지원하면 View Transition으로 지도 교차 페이드(나감 `--m-1`, 들어옴 `--m-2`, 쇼룸 `ky-seg` 방식), 아니면 지금처럼.
- 시트: 데스크톱 `translateY(8px) scale(.985)`+opacity → 끝 `--m-2 --m-out`, 휴대폰 아래 시트 `translateY(100%)` → 0 `--m-3 --m-out`, 배경막 opacity `--m-2`, 안의 블록 `rise`(8px) `--m-stagger` 간격(최대 8개). 닫힘 `--m-1` opacity + 4px.
- 종목 페이지 열기(`fancy`, View Transition 지원 시): 누른 타일과 종목 페이지 머리를 같은 `view-transition-name`으로 이어 `--m-3 --m-inout`(쇼룸 `ky-photo`처럼 사진이 시트로 커지는 느낌). 미지원이면 지금 그대로.
- 미리보기 카드(coss·reui 방식): 마우스·펜(`hover:hover and pointer:fine`)일 때 시장 띠 항목, 사이드 순위 행, 해외 목록 행, 같은 업종 종목, 검색 결과에. 열림 지연 400ms·닫힘 150ms, 하나가 열린 상태에서 옆 항목으로 옮기면 지연 없이 바꾸고 카드가 τ 70ms로 따라가요. `scale .98→1`+opacity 150ms `--m-exit`, 원점은 트리거 쪽 변. 내용: 이름·값·대비·당일 스파크라인(`fancy`면 선을 `--m-3`로 그려 나감). 포커스로도 같은 지연 후 열리고 Esc로 닫혀요. 지도 타일 툴팁은 지금처럼 즉시 뜨되, `fancy`면 τ 50ms로 따라가고 숨김 120ms 지연(타일 틈에서 깜박임 방지).
- 실시간 점: `fancy`면 무한 맥동 대신 `kh:data` 때마다 한 번 맥동 — 진짜 갱신 박자를 보여 줘요.
- 플랩 시계(§3-6): 위 반쪽 `rotateX 0→−90°` 120ms `(.4,0,1,1)`, 아래 반쪽 `90→0°` 120ms `--m-out`, 중간 숫자 장당 60ms(최대 4장), 넘어가는 판에 그림자 α 0→.35. 시계를 눌러 새로고침할 때는 모든 칸이 한 번 섞이듯 넘어가고(`fancy`, 칸마다 30ms 간격), 갱신이 끝날 때까지 진행 막대 끝에 앰버 점 하나만 맥동해요(`standard`는 칸 하나만 0.25초 넘김).
- 포커스 고리는 애니메이션 없이 바로.

### (h) 분위기 효과 (선택) — 데이터 화면에는 아주 조금만
- 그레인: 지도·표·숫자 위에는 **올리지 않아요**(색 정확도와 작은 글자 대비가 떨어지고, 고정 전체 화면 층은 매 스크롤 합성 비용). 지도 밖 바닥(`#131418`)과 머리글에만 `background-image`로 붙이고(별도 층 아님) 불투명도 .025~.035, 정적(떨림 애니메이션 없음). 180px 타일 SVG `feTurbulence type=fractalNoise baseFrequency=.85 numOctaves=2` + 채도 0 — aerive 값을 낮춰 쓴 것.
- 그라데이션: 머리글 뒤에만 장 구간 색(§3-6 진행 막대 색)의 반지름 그라데이션 α .06~.08. 구간이 바뀔 때 2.4초 교차 페이드, 계속 흐르게 하지 않아요. 지도 뒤에는 절대 두지 않아요. 정보(지금 장 구간)를 담을 때만 정당해요.
- 그라데이션이 있는 곳(밤 겹, 머리글 빛, 3D 바닥)은 그레인이나 디더로 띠무늬를 없애요. 저사양·`saveData`면 분위기 효과는 꺼요.

## 3. 빌리지 않을 것 · 성능 예산

- **스무스 스크롤·스크롤 잠금(Lenis 등)**: 지도 끌기, 시트·표 안쪽 스크롤과 싸우고 입력 지연(lerp .1)이 생겨요. 쇼룸도 터치는 기본 스크롤(`syncTouch:false`)이에요.
- **스크롤 연동 연출**(`animation-timeline: view()`, 패럴랙스, Shopify식 장마다 화면 전체 색 바꿈, 고정 스토리텔링): 한 화면짜리 데이터 앱엔 보여 줄 장면이 없고, 빨강·초록·앰버 외의 넓은 색면은 색 규칙과 충돌해요.
- **긴 첫 화면 연출**(scrolltide 1.2~2.4초, 막·로고 등장, 입력 차단): 첫 진입은 700ms 이내, 세션당 한 번, 입력하면 즉시 끝.
- **blur 등장**(aerive `filter: blur` 700ms): 타일 수백 개에 filter 애니메이션은 비싸고 숫자를 흐려요.
- **끝없는 장식 반복**(이미지 마키, 떠다니는 물체, 링 회전, 글자 광택 5초, `gradient-shift`): 숫자를 읽는 동안 주변 시야를 뺏어요. 예외는 정보인 것(시장 띠 티커, 열린 시장 맥동, 갱신 맥동).
- **영문 대문자 고정폭 라벨·화면을 덮는 거대 제목**: 쇼룸·Shopify의 크기·굵기·자간만 가져오고, §4(해요체, 대문자·영문 장식 없음)를 따라요. 새 글꼴(JetBrains Mono 등)은 추가하지 않고 Pretendard tabular로.
- **overshoot·탄성**(`backOut`, `(.34,1.56,.64,1)`, pop 1.08): 값보다 큰 순간이 생겨요. 자동 회전 카메라, 지도 위 `mix-blend-mode` 겹(색 왜곡), HTML-in-Canvas(Shopify, Chrome 오리진 트라이얼)도 제외.
- **예산**: 중급 휴대폰(390px, CPU 4배 감속 프로파일)에서 타일 300개(전체 600개) 60fps. 프레임당 JS ≤ 4ms, 애니메이션 중 레이아웃 0(transform·opacity·`::after` opacity만; 색 트윈은 리플레이에서 30Hz 이하만). 좌표는 DOM 측정 대신 `KH.layout()` 값, 읽기를 먼저 모으고 쓰기는 나중에. `will-change`는 애니메이션 동안만 붙였다 떼요(600개 상시 금지). 동시 실행: 플래시 ≤ 60, 오도미터 자리 ≤ 120(보이는 것만), 맥동 고리 ≤ 25. `document.hidden`이면 rAF 취소 + 무한 CSS 애니메이션 `paused`, 화면 밖(IntersectionObserver)도 같음. long task 50ms 미만.
- **레벨 지키기**: 모든 새 코드는 `KH.motion() === 'fancy'`를 확인하고 아니면 최종 상태만 그려요. `reduced`면 기존 전환도 끄고(지금 FLIP 포함), 3D는 정적 자세, 숫자는 즉시 교체. `kh:motion`을 듣고 진행 중인 것은 `finish()`.
