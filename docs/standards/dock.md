## 0. 한 줄 규칙

지도가 막대 자리 위로 **다 지나간 뒤에만** 화면 아래에 떠서 따라오는 높이 56px 막대예요. 이미 화면에 있는 숫자(같은 저장소 · 같은 가격 기준 · 같은 시각)만 보여 주고, 칸을 누르면 그 숫자의 자세한 곳으로 가요. 오른쪽 끝에 🔍 검색 키가 늘 있어요.

## 2. 내용 (칸)

| 칸 | 보이는 글자 | 값의 출처 (새 경로 없음) | 누르면 |
|---|---|---|---|
| **지수** | 이름 · 등락률 / 값 · 오늘 선(44 × 18) | `KH.index()`의 값 · 등락률(시장 띠 · 탭 아래 숫자와 같음), 선 = §3-20 지도 머리줄 선과 같은 배열(`/api/market` spark + 실시간 마지막 점) | 지수 상세 시트 `KHWorld.openDetail(key, {opener})` — 오늘 선 포함(§3-22) |
| **관심** | ★ 그룹 이름 · 종목 수 / 그룹 등락률 · 가장 많이 움직인 종목 | ★관심 탭 아래 숫자와 **같은 함수 · 같은 그룹**(`khm.watchTabGroup`, 시총 가중, 고른 가격 기준) | ★관심 탭으로 바꾸고(그 그룹) 지도 머리줄로 스크롤 |
| **등락 분포** | "등락 분포" · 전체 수 / 쌓인 막대 / ▲상승 · 보합 · ▼하락 | 등락 분포 카드가 그리는 **같은 계산 결과**(범위 · 가격 기준 · "일부만 반영" 표시까지 같음) | 등락 분포 카드로 스크롤(붙은 머리글 아래 8px), 카드 제목에 포커스 |
| **🔍** | 돋보기 아이콘 | — | 검색 시트 (§5) |

- **지수 칸 "내가 설정한 지수"**: `지수 칸: 탭 따라 · 코스피 · 코스닥` (기본 탭 따라). 지수가 없는 탭(테마 · 관심 · 해외 · 원자재)에서 "탭 따라"는 마지막으로 본 국내 지수 탭(없으면 코스피).
- 색: 등락 글자 `--up-text/--dn-text`, 쌓인 막대 = 팔레트 끝색 · 중립색(등락 분포 카드와 같은 색). ▲ ▼ 기호가 같이 있어 색만으로 말하지 않아요. 강조(★)는 테마의 `--acc`.
- 다시 보기 중: 칸들도 그 시점 값(탭 숫자와 같은 규칙, §3-16 · §3-18). 스냅샷: 스냅샷 값.
- 값이 없을 때: 관심종목 없음 → 관심 칸 "관심종목이 없어요"(누르면 ★관심 탭), 지수 선 없음 → 선 자리 비움, 등락 분포 실패 → 지도 종목 분포로 바뀌고 카드와 같은 문구.

## 3. 언제 뜨고 숨나

- **뜸**: 지도 보기에서 지도 상자(`.mapw` 또는 해외 `#world`) 아래 끝이 `화면 높이 − 72px`(8 + 56 + 8) 위로 올라갔을 때. 그래서 **첫 화면에서도, 스크롤 중에도 지도를 덮지 않아요**(시안 측정: 4테마 × 4프레임, 40px 간격 훑기에서 겹침 0). 표 보기 · 목록 보기는 머리줄(`.stagebar`)이 붙은 머리글 아래로 지나갔을 때.
- **숨음**: 다시 올라와 위 조건이 깨질 때, 그리고 빠른 시트 · 표시 설정 · 종목 페이지 · 그룹 고르기 · 티커 고르기 · 다시 보기 플레이어 · 작은 창 · 검색 시트 · 지수 상세가 열려 있을 때(템플릿의 열린 창 수 > 0이면 숨김), 화면 키보드가 열려 있을 때(`visualViewport.height < innerHeight × .75`), 화면 폭 > 760.
- **끝 자리**: 막대가 켜져 있으면 페이지 끝(출처 줄 아래)에 `72px + env(safe-area-inset-bottom)`을 **늘 비워 둬요**. 보일 때만 덧붙이면 끝에서 화면이 밀려요. 시안 측정: 끝까지 내리면 출처 글자 아래 끝과 막대 위 끝 사이 109px.
- 숨은 막대는 `visibility:hidden` + `aria-hidden="true"` — 탭 순서에 안 잡혀요.

## 4. 모양 · 크기

- `position:fixed; left:8px; right:8px; bottom:calc(8px + env(safe-area-inset-bottom)); height:56px; padding:6px`. 칸 높이 44, 🔍 키 44 × 44.
- 재질은 테마 토큰(`themes.md` §4-2): `--dock-bg` · `--dock-sh` · `--dock-r` · `--dock-div`. 기본 = 어두운 판 + 1px 선, 신문 = 종이 + 1px 먹 테 + `3px 3px 0` 먹 그림자(오려낸 쪽지), 글라스 = 두꺼운 유리 모양이지만 **블러 없음**(막대는 지도가 다 지나간 뒤에만 떠서 아래에 비칠 색이 없고, 블러 판 예산 2장을 아껴요).
- 칸 사이 1px 나눔 선(`--dock-div`, 장식 — 칸 구분은 여백과 글자가 해요).
- 🔍 키 = 솟은 키(controls §5-1 · §5-2): `--key-bg/--key-sh`, 누름 1px + `--key-dn` + `--press-f`. 모서리 `--r-key`(글라스는 원).
- 칸 = 목록 줄 규칙(controls §5-1): 누르면 가라앉지 않고 `filter: var(--press-f)`만. 포커스 고리 3px, 칸 안쪽(`-3px`), 키는 바깥 2px.
- 글자: 값 16px(V1 · V3 17px) 700 tabular, 보조 11.5px. 한 줄에 안 들어가면 이름부터 말줄임.

## 5. 🔍 검색

- **위치: 오른쪽 끝(추천)**. 안드로이드의 오른손 한 손 쥠에서 엄지가 닿는 아래 오른쪽 · 머티리얼 떠 있는 버튼 자리와 같고, 왼쪽부터 읽는 내용이 막대 처음에 와요. 설정 `돋보기: 오른쪽 · 왼쪽`으로 왼손 사용자가 바꿀 수 있어요(시안의 "돋보기" 조작).
- **누르면: 검색 시트**(같은 검색을 아래 시트에) — "맨 위로 올라가 검색 칸에 포커스"는 고르지 않았어요. 까닭: ① 읽던 자리(카드 · 목록)가 그대로 남아요, ② 입력 칸과 결과가 엄지 가까이 와요, ③ 수천 px를 올라가는 동안 키보드가 늦게 뜨고, 그 사이 붙은 머리글 · 막대가 바뀌어 화면이 출렁여요, ④ 안드로이드 "뒤로"로 시트가 닫혀요(다른 시트와 같은 history 처리).
- 시트: 위에 검색 칸(44px, 글자 16px — 안드로이드 크롬이 확대하지 않아요) + ✕, 아래 제안 목록(48px 줄: 캔들 아이콘 · 이름 · 업종 · 현재가 · 등락률). **같은 `searchList()`와 같은 `pick()`** — 고르면 지금처럼 빠른 시트(휴대폰). 키보드 처리: `visualViewport` 높이에 맞춰 시트 높이를 정해 키보드 위에 붙어요(`interactive-widget=resizes-content`를 쓰면 CSS만으로도 돼요 — 구현 때 확인).
- 포커스: 열면 검색 칸, 닫으면(✕ · 바깥 · Esc · 뒤로) 🔍 키로. 키보드로도 ↑ ↓ Enter(시안 측정: Esc 뒤 포커스 🔍 복귀).
- **막대 내용을 꺼도 🔍는 남아요**: 56 × 56 작은 판에 키 하나(오른쪽 또는 왼쪽 끝).

## 7. 붙는 머리글과 함께 — 높이 예산

- 글라스 · 신문(그리고 제안대로면 기본)은 휴대폰에서 탭 줄(56px)이 붙어 따라와요. 막대는 72px. 합 128px.
- 측정(시안 프레임) · 어림: 390 × 844 → 15.2%(남는 높이 716px), 안드로이드 크롬 주소 줄 숨김 약 790 → 16.2%, 주소 줄 보임 약 734 → 17.4%, 360폭 휴대폰 주소 줄 보임 약 680 → 18.8%, 360 × 640 → 20%.
- **규칙: (붙은 머리글 + 막대) / 화면 높이 > 18%면 내릴 때 머리글이 접히고 올릴 때(4px 넘게) 돌아와요. 막대는 그대로.** 18%인 까닭: 보통 안드로이드 화면(약 712px 이상)에서는 사용자가 원한 대로 머리글 · 막대가 둘 다 따라오고, 작은 화면 · 가로 화면 · 화면 나누기에서만 접혀요(16%로 잡으면 주소 줄을 숨긴 보통 화면에서도 접혀서 "머리글이 따라오게" 요청과 어긋나요). 막대를 접지 않는 까닭: 사용자가 원한 건 "내려갈 때 따라오는" 막대이고, 올릴 때는 탭 줄(지도 이동)이 더 필요해요. 줄이기면 접고 펴는 게 바로.
- 이 규칙은 머리글이 붙는 모든 테마에 같아요. 사용자 휴대폰의 실제 화면 높이로 한 번 확인이 필요해요(실기기 확인 못 함).

## 9. 접근성

- 막대 `role="region" aria-label="아래 막대"`. 칸은 버튼, `aria-label`에 값 전체와 누르면 할 일("코스닥 638.97, −5.30 (−0.82%), 오늘 흐름 — 누르면 지수 상세").
- 값 갱신은 읽어 주지 않아요(1분마다 다시 읽히지 않게). 막대가 떴다고 알리지도 않아요(내용은 페이지에 이미 있어요).
- V3를 고르면 쪽마다 `aria-roledescription="쪽"` + "1/3", 키보드 ← → 로 넘김.
