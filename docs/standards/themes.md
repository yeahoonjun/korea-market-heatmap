## 0. 한 줄 규칙

테마는 **역할 토큰 한 벌**이에요. 크기 · 간격 · 시간 · 배치 · 글꼴(Pretendard)은 모든 테마가 같고, **색 · 빛 · 모서리 · 재질 · 글자 굵기**만 달라요. 그래서 테마를 바꿔도 지도 위치와 타일 배치는 1px도 움직이지 않아요(§14). 빨강 · 초록은 등락에만, 강조는 테마마다 앰버 계열을 재질에 맞게. **시계는 어느 테마에서나 지금 사이트 모양 그대로**예요(§3).

### 1-1. 밝은 테마 = 승인된 예외 (사용자 2026-11-13)

AGENTS.md §4 "다크 톤. 지도 바닥은 `#000`, 화면 `--page #131418` … 강조색은 앰버 `#ffb547`"과 맞지 않는 **신문 · 글라스 밝게**는 사용자가 **이번만 예외**로 승인했어요(19:45 ④). 그래서:
- AGENTS §4는 그대로예요(개정 제안 안 해요). 기본값은 **기본(어두운) 테마**이고, 밝은 테마는 사용자가 표시 설정에서 고를 때만.
- 예외 범위: 이 문서의 신문 · 글라스 밝게 토큰(§4)만. 다른 화면 규칙(빨강 · 초록 = 데이터, 해요체, 출처 · 시점 표기)은 밝은 테마에도 그대로.
- 다른 밝은 테마를 더하려면 다시 사용자 결정이 필요해요.

| 이름 | 구현 id (시안 id) | 한 줄 | 상태 |

| 글라스 밝게 | `glass-light` (`glassB`) | 흰 유리 판, 밝은 지도(밝은 바탕용 팔레트) | 출시 · 밝은 테마 예외 |

| | **안 A · 네 칸 한 번에 (추천)** | 안 B · 세 칸 + 밝기 줄 |
|---|---|---|
| 모양 | `기본 · 신문 / 글라스 어둡게 · 글라스 밝게` 2 × 2 세그먼트, 칸마다 바탕 · 키 · 강조 견본 | `기본 · 신문 · 글라스` + 아래 `글라스 밝기: 어둡게 · 밝게`(글라스가 아니면 꺼짐) |
| 누름 수 | 1 | 글라스 밝게는 2 |
| 장점 | 칸마다 완성된 모습 하나, 따로 켜지는 줄이 없어요 · 밝은 테마가 "예외"라는 게 이름으로 보여요 | 나중에 "기기 설정 따라"를 밝기 줄에 붙이기 쉬워요 |
| 단점 | 칸이 넷이라 줄이 둘 | 밝기 줄이 신문 · 기본에서 뜻이 없어 늘 꺼진 채 자리만 차지 |

추천은 **안 A**: 결정이 한 번에 끝나고, 밝은 테마가 기본 · 글라스 어둡게와 같은 무게로 보이지 않게(견본이 밝게 보여요) 해요. 바로 아래에 `명조 제목`(신문에서만 켜짐, 기본 꺼짐)과 `유리 흐림: 자동 · 끄기`(글라스에서만)를 둬요. 둘 다 다른 테마에서는 꺼진 채(`opacity .45`, controls §5-12) 자리를 지켜서 시트 높이가 테마마다 같아요.

저장: `khm.theme` = `base|paper|glass-dark|glass-light`(없거나 모르는 값이면 `base`), `khm.set.serif`(기본 false), `khm.set.glassBlur` = `auto|off`.

## 3. 바뀌지 않는 것

- 크기 · 여백 · 높이 · 너비 · 글자 크기 · 줄 높이, 컨트롤 길이 · 곡선(`--c-*`, `--m-*`), 배치(컨테이너 쿼리 경계), 타일 배치, 아이콘 모양, 문구.
- 컨트롤 구조(controls.md): 누름 1px + `--key-dn` + `--press-f`, 걸린 키, 세그먼트 앞 fast · 뒤 base, 비동기 글자 상자, ✓ / ! + 글자.
- 선은 `box-shadow`(inset)로 → 테마가 선을 더해도 상자 크기가 안 변해요.
- **시계 (19:45 ⑤)** — 지금 사이트(`src/extras/extras.js` `ckAnalogSvg`, `extras.css` `.xc-*`) 그대로, 모든 테마 같아요:
  - 아날로그 판: 어두운 테 `#2a2c33` · 미색 판 `#f4f1e8` · 안쪽 고리 `#d9d5c8` · 막대 눈금과 시 · 분침 `#17181c`(바늘 안에 미색 줄) · 분 점 `#6b6a64` · **빨간 초침 `#e5231b`**(폭 2.6 막대 + 꼬리 막대 + 끝 가까이 원판 r 5.6 + 가운데 축 r 2.8, 축 테 `#17181c`). 이 색들은 **고정값**이고 테마 토큰으로 바꾸지 않아요. 초침은 앰버가 아니에요.
  - 숫자: 사이트처럼 **판 없는** tabular 숫자(650, 데스크톱 30px · 휴대폰 26px), 쌍점 · 초는 `--muted`. 숫자 색은 사이트 그대로 본문 글자색 `--fg`라서 종이 · 밝은 유리 위에서는 먹색으로 읽혀요 — 테마 색을 입히는 게 아니라 글자색을 따르는 것이에요.
  - 참고: AGENTS §3-6의 "플랩(어두운 회색 판 · 미색 숫자)"은 2026-11-10에 숫자만 남는 모양으로 바뀌었어요(커밋 `8fd68c4` "clean digital clock replaces split-flap"). 시안은 지금 코드 모양을 따랐어요.
  - 종이 · 밝은 유리 위에서 읽힘: 판(미색) · 테(어두운 회색) 중 큰 쪽 대비가 바탕 대비 11.6 · 11.6:1(신문 · 글라스 밝게), 16.3 · 17.3:1(기본 · 글라스 어둡게). 어두운 테가 밝은 바탕과 판을 갈라 줘요.

### 4-4. 그 밖

- 진행 막대 구간 색(`--sb-*`, §3-6 시간대 색): 신문은 같은 색상환에서 채도를 낮추고 조금 짙게(종이 위 인쇄 잉크), 지난 구간 불투명도 `--sb-rest` .22. 빨강 · 초록은 여전히 안 써요. 시계(§3)와 달리 테마 토큰이에요(사용자 결정은 시계만 고정).
- 브라우저 상단 색 `<meta name="theme-color">`: 테마의 `--page`.

## 5. 글자

- **모든 테마 Pretendard Variable**. 크기 · 줄 높이는 같고 굵기 · 자간만: 제목(`--w-head`) 기본 600 · 신문 800 · 글라스 650, 강한 글자(`--w-strong`) 기본 700 · 신문 800, 제목 자간(`--track-head`) 기본 −.02em · 신문 −.03em. 숫자는 늘 `tabular-nums`(+ 신문 `lining-nums`).
- 신문 느낌은 글꼴이 아니라 배치 · 선 · 굵기 · 단 · 종이색에서: 카드는 위 굵은 먹줄로 시작하는 단, 지도와 옆 칸 사이 세로 가는 줄, 굵은 제목.
- **명조 제목 = 신문 테마의 사용자 설정, 기본 꺼짐**(19:45 ①). 켜면 카드 · 지도 · 시트 제목, 종목 페이지 이름 자리, 큰 숫자(등락 분포 %, 툴팁 · 시트 · 종목 페이지 현재가, 지수 값, 아래 막대 값)만 Noto Serif KR(OFL 1.1). 본문 · 표 · 타일 · 컨트롤은 Pretendard 그대로. 줄 높이 고정이라 켜고 꺼도 배치가 같아요(측정 §14). 신문이 아닌 테마에서는 설정이 꺼진 채 보이고 값은 기억해요(신문으로 돌아오면 다시 적용).
- 구현 때 서브셋: 종목 이름은 수천 개라 명조로 쓰지 않아요 → **고정 제목 글자 + 숫자 · 기호만**(시안 서브셋 19 KB). 종목 페이지 이름 자리는 Pretendard로 두는 게 맞아요.

## 6. 재질

### 6-1. 종이 (신문)
- 질감 이미지 없음(단색). 섬유 노이즈는 버려요(전체 화면 필터 · 이미지 저장에서 얼룩).
- 선의 위계: 가는 선(먹 α .2) < 1px 먹 테(지도 · 툴팁 · 키 · 아래 막대) < 카드 위 2px 먹줄 < 머리글 아래 1px 먹줄 + 시트 위 겹줄.
- 활판 키: 솟음 `0 2px 0` 먹, 누름 `0 1px 0` + 1px 내려감.
- 오려낸 쪽지: 툴팁 `4px 4px 0`, 아래 막대 `3px 3px 0`(작은 면이라 조금 얕게).
- 신문 B와 함께 버린 것: 먹 뒤집기 세그먼트, 검은 섹터 띠, 망점 막대, 점선 행.

## 10. 성능 예산

**규칙**
1. 블러는 지도 위에 뜨는 크롬에만: 붙은 머리글 · 툴팁 · 시트 · 팝오버 · 말풍선 · 플레이어. 타일 · 카드 · 행 · 키 · **아래 막대**에는 0개.
2. 한 화면에 블러 판 최대 2장(붙은 머리글 + 떠 있는 판 하나). 반경 머리글 20px, 판 24px.
3. 휴대폰 붙은 머리글은 탭 줄(약 390 × 56)만.
4. 신문 · 기본(제안)의 따라오는 머리글은 불투명 · 블러 없음.
5. 대체 모습 · 프레임 감시 §6-2.

**측정 (샌드박스 추정, 실기기 아님)**: 390 × 844, DPR 2, 터치, CPU 4배 느리게, 휴대폰 프레임 지도 597타일만 그림(`only=fw-p2`), rAF마다 12px 스크롤 295프레임, 머리글이 붙고 아래 막대가 뜬 상태. 헤드리스 크롬에 GPU가 없어 합성이 CPU예요 — **같은 실행 안의 상대 비교로만** 보세요(이번 실행은 1차 때보다 전체가 느려서, 블러 · 층이 없는 상태로 되돌려도 기본이 142~166/295였어요).

## 15. 구현 나누기 (모듈별) — 사용자가 아래 막대 변주를 고른 뒤, 따로 에이전트가 실행

순서(controls.md와 같은 방식): **① 템플릿 → ② extras → ③ 종목 페이지 → ④ 해외**. 단계마다 그 모듈 담당 에이전트가 자기 worktree(`feat/theme-<모듈>`)에서 커밋, 오케스트레이터가 병합 · 배포. 단계마다 360/390/768/1280/1920 × 4테마 스크린샷 · 대비 · 지도 위치 측정. 다른 모듈은 **토큰이 없으면 지금 값**으로 보이게 `var(--x, 지금값)`.

색 개수는 `tmp/themes/inventory.py`로 센 **글자 그대로 적힌 색**(16진 · rgb/rgba)이에요. 템플릿의 `:root` 토큰 정의는 뺐어요.

### 15-1. `src/template.html` (히트맵 담당) — 먼저

- **토큰 넣기**: `:root`는 기본 값 그대로 + `html[data-theme="paper"]`, `[data-theme="glass-dark"]`, `[data-theme="glass-light"]` 묶음(시안 `.site[data-theme=…]` 블록 그대로). ✚ 새 토큰: `--acc --acc-fill --acc-line --focus --acc-soft --acc-bd --rule --map-bg --sec-bg --sec-fg --ihd-bg --ihd-fg --tile-hov --sel-1 --sel-2 --card-bg --card-bd --card-r --card-sh --row-bd --sheet-bg --sheet-bd --sheet-sh --sheet-r --tip-bg --tip-bd --tip-sh --tip-r --scrim --blur --blur-bar --bar-bg --bar-sh --r-map --w-head --w-strong --track-head --font-head --spark-fill --sw-on --dock-bg --dock-sh --dock-r --dock-div`. `--amber`는 `--acc-fill`의 별칭으로 남겨 다른 모듈이 깨지지 않게.
