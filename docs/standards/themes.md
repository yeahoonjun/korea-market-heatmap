## 0. 한 줄 규칙

테마는 **역할 토큰 한 벌**이에요. 크기 · 간격 · 시간 · 배치 · 글꼴(Pretendard)은 모든 테마가 같고, **색 · 빛 · 모서리 · 재질 · 글자 굵기**만 달라요("크기와 시간은 테마가 같고 색 · 빛 · 모서리만 달라요" — 사용자 컨트롤 레퍼런스의 생각 그대로). 그래서 테마를 바꿔도 지도 위치와 타일 배치는 1px도 움직이지 않아요(시안에서 측정, §14). 빨강 · 초록은 등락에만, 강조는 테마마다 **앰버 계열을 재질에 맞게** 바꿔 써요.

- **신문 B**: 검은 섹터 띠와 틈이 600~2,600개 타일을 묶음별로 또렷하게 갈라 줘요(지금 사이트가 `#000` 틈으로 하는 일과 같아요). 사용자 시안 B5의 먹 뒤집기 · 망점 · 오려낸 쪽지가 가장 잘 살아요. 따뜻한 종이색만 좋으면 A의 종이 · 먹 값을 B에 얹는 "B 구조 + A 색"도 가능해요(토큰만 바꾸면 돼요).
- **글라스 A**: 유리는 아래에 비칠 것이 있어야 살아요 — 선명한 어두운 지도가 그 바탕이에요. 기본 테마와 색 체계가 같아서 위험이 가장 적어요. B는 밝은 지도라 등락 색이 덜 강렬해요.

선택은 `표시 설정 › 화면 › 테마: 기본 · 신문 · 글라스`(시안의 표시 설정 시트에 `새로` 표시로 넣어 두었어요). A/B는 지금 고르고 출시는 테마당 하나만.

## 3. 바뀌지 않는 것

- 크기 · 여백 · 높이 · 너비 · 글자 크기 · 줄 높이, 컨트롤 길이 · 곡선(`--c-*`, `--m-*`), 배치(컨테이너 쿼리 경계), 타일 배치(같은 트리맵), 아이콘 모양, 문구.
- 컨트롤 구조(controls.md): 누름 = `translateY(1px)` + `--key-dn` + `--press-f` 0ms/180ms, 열린 키는 눌린 채 걸림, 세그먼트 앞 가장자리 fast · 뒤 base, 비동기 글자 상자(최장 폭), ✓ / ! + 글자.
- 테두리 대신 그림자(`inset`)로 선을 그려요 → 선이 생겨도 상자 크기가 안 변해요. 신문의 겹줄 · 위 굵은 줄도 `box-shadow`예요.
- 측정(시안, 1280 · 390 프레임): 지도 · 머리글 · 탭 · 시장 띠 · 도구 줄 · 지도 머리줄 · 옆 칸 · 시트 상자, 타일 300개 배치 서명 — **5개 테마 모두 같음**. 명조 제목 켬, 블러 없는 대체 모습도 같음(§14). 다른 곳은 하나 — 글라스의 "스크롤 중" 프레임에서 머리글이 지도 위에 붙어 따라오는 것(의도, §9).

### 4-4. 그 밖

- 진행 막대 구간 색(`--sb-*`): 신문은 같은 색상환에서 채도를 낮추고 조금 짙게(종이 위 인쇄 잉크), 지난 구간 불투명도 `--sb-rest` .22 / .20. 빨강 · 초록은 여전히 안 써요.
- 시계: 아날로그 판(`--face`, `--face-ink`)과 플랩 칸(`--flap-bg/fg/gap`). 신문 B는 검은 플랩 + 종이색 숫자, 가운데 틈은 종이 α .22(숫자에 줄 그은 것처럼 보이지 않게). 초침은 `--hand-sec`(기본 앰버, 신문 황토).
- 브라우저 상단 색 `<meta name="theme-color">`: 테마의 `--page`(구현 때).

## 5. 글자

- **모든 테마 Pretendard Variable**(사용자 2026-11-13 18:41). 크기 · 줄 높이는 같고 **굵기 · 자간만** 달라요: 제목(`--w-head`) 기본 600 · 신문 800 · 글라스 650, 강한 글자(`--w-strong`) 기본 700 · 신문 800, 제목 자간(`--track-head`) 기본 −.02em · 신문 A −.03em · 신문 B −.035em. 숫자는 늘 `tabular-nums`(+ 신문 `lining-nums`).
- 신문 느낌은 글꼴이 아니라 **배치 · 선 · 굵기 · 단 · 종이색**에서 와요: 카드는 상자 대신 위 굵은 먹줄로 시작하는 단, 지도와 옆 칸 사이 세로 가는 줄, 머리글 아래 겹줄(B), 점선 행(B), 굵은 제목.
- "작은 대문자" 같은 영문 장식은 쓰지 않아요(AGENTS §4). 한국어에선 작은 라벨을 굵기 한 단계 + 흐림색으로 구분하는 지금 방식 그대로.
- **명조 제목(선택지, 신문만, 기본 꺼짐)**: 켜면 카드 제목 · 지도 제목 · 시트 제목 · 종목 페이지 이름 · 큰 숫자(등락 분포 %, 툴팁 · 시트 · 종목 페이지 현재가, 지수 값)만 Noto Serif KR(OFL 1.1). 본문 · 표 · 타일 글자 · 컨트롤은 Pretendard 그대로. 시안의 서브셋은 18 KB(그 자리 글자만). 줄 높이를 고정해 켜고 꺼도 배치가 같아요(측정). 구현 때는 보이는 이름이 종목마다 바뀌어서 **이름에는 쓰지 않고 숫자 · 고정 제목에만** 쓰는 게 맞아요(서브셋이 커지지 않게).

## 6. 재질

### 6-1. 종이 (신문)
- **질감 이미지 없음**: 종이는 단색. B5의 섬유 노이즈(SVG `feTurbulence` 전체 화면)는 버려요 — 무겁고(전체 화면 필터), 데이터와 무관하고, 이미지 저장 · 인쇄에서 얼룩이 돼요.
- 선의 위계: 가는 선(먹 α .17~.2) < 행 점선(B) < 1px 먹 테(지도 · 툴팁 · 키) < 카드 위 2~3px 먹줄 < 머리글 아래 겹줄(B).
- **활판 키**: 솟음 = `0 2px 0` 먹 그림자(번지지 않는 딱딱한 그림자), 누름 = `0 1px 0` + 1px 내려감 → V1의 "솟은 키가 1px 가라앉음"이 인쇄 재질로 그대로 읽혀요.
- **먹 뒤집기**(신문 B 세그먼트): 고른 칸 = 먹 칸 + 종이색 글자(B5의 선택 표현). 탭만은 등락률 숫자 색이 먹 위에서 안 읽혀서 흰 칸 + 먹 막대.
- **오려낸 쪽지 툴팁**(B5): 종이 + 1px 먹 테 + `4px 4px 0` 먹 그림자, 블러 없음.
- **망점**(신문 B, B5): 옆 카드의 막대(등락 분포 · 상승/보합/하락 띠 · 섹터 막대)만 `radial-gradient` 4px 점. **지도 타일에는 쓰지 않아요**(타일 글자 대비가 떨어지고 2,600개 타일에 그라데이션 칠하기 비용).

### 6-2. 유리 (글라스)
두께 두 가지 + 블러 없는 유리. 블러는 **지도 위에 뜨는 크롬에만**, 타일 · 카드 · 행에는 절대 안 써요.

| 재질 | 어디 | 레시피 (A / B) |
|---|---|---|
| 얇은 유리 | 머리글 — 가장자리에서 떨어진 둥근 판(데스크톱 위 4px · 옆 6px · 모서리 18px, 휴대폰 2px · 4px · 24px; 판은 `::before` 그림이라 배치는 그대로), 지도 위에 붙어 뜰 때 블러 | `rgba(16,18,24,.62)` / `rgba(246,247,250,.64)` + 위 흰 그라데이션 + `backdrop-filter: blur(20px) saturate(1.6)`, 아래 .5px 빛줄. 탭 트레이(검정 α .34)가 한 겹 더 깔려 탭 글자 바탕은 사실상 .75 이상 |
| 두꺼운 유리 | 툴팁 · 빠른 시트 · 설정 시트 · 말풍선 · (구현 때) 팝오버 · 다시 보기 플레이어 | `rgba(20,22,28,.84)` / `rgba(248,249,251,.86)` + 위 흰 그라데이션 + `blur(24px) saturate(1.4)` + 위 1px 빛 + .5px 테두리 빛 + 깊고 부드러운 그림자 |
| 블러 없는 유리 | 카드 · 키 · 칩 · 세그먼트 · 종목 페이지 칸 | 반투명 채움 + 위 반사광 그라데이션 + `inset` 빛/그늘(테두리 빛), 블러 없음(아래가 바탕뿐이라 블러가 할 일이 없어요) |
| 테두리 반사광 | 큰 유리면(머리글 · 판 · 카드) | `::after` 1px 고리를 `mask-composite: exclude`로 — 왼쪽 위 · 오른쪽 아래가 밝은 그라데이션(굴절 렌즈의 가장자리 빛을 흉내) |
| 포인터 반사광 | 떠 있는 판(화려하게만) | 판 위 160px 원형 하이라이트가 포인터를 따라와요(rAF로 판 하나만, CSS 변수 두 개) |

- 판 두께 .84/.86은 대비 때문이에요: 판 아래에 가장 밝은(B는 가장 어두운) 지도 색이 한 면 가득 깔린 최악에서도 흐림 글자 · 등락 글자가 4.5:1을 넘게(§8).
- **굴절(displacement) 필터는 버려요**: `backdrop-filter: url(#svg)`는 Chromium만 되고(사파리 안 됨) 비용이 커요. 가장자리 반사광 + 그라데이션으로 렌즈 느낌만 내요.
- **대체 모습**(시안 `블러 없는 대체 모습`): `@supports not (backdrop-filter)` · `prefers-reduced-transparency: reduce` · (구현 때) 저전력 감지 · 설정 → 같은 색의 **불투명 판**(A `#1b1d23`, B `#f4f6f9`, 머리글 A `#14161b`, B `#eef1f5`). 모양 · 테두리 빛은 그대로라 같은 테마로 보여요.
- 움직임 줄이기: 포인터 반사광 없음, 나머지 재질은 정적이라 그대로.

## 7. 데이터 색 (팔레트 × 테마)

- 사용자 팔레트 선택(빨강 상승 · HTS 색 · 초록 상승 · 색각 친화)은 **모든 테마에서 그대로** 적용돼요. 테마는 같은 의미(상승 색 · 하락 색)를 그 바탕에 맞는 잉크로 다시 칠할 뿐이에요.
- 기본 · 글라스 A: 지금 7단 색 그대로(글라스 A만 빨강 글자를 `#ff6b74`로 아주 조금 밝게 — 유리 판 위 대비).
- 밝은 테마(신문 A · B, 글라스 B): `[짙은 하락, 중립과 72%, 42%, 중립, 42%, 72%, 짙은 상승]` 7단. 0% = 테마 중립 회색(신문 A `#dacbbb`, 신문 B `#d6d5cf`, 글라스 B `#cfd3da`), 끝은 짙은 잉크.

## 9. 성능 예산 (글라스)

**규칙**
1. 블러(`backdrop-filter`)는 지도 위에 뜨는 크롬에만: 머리글(붙어 뜰 때) · 툴팁 · 시트 · 팝오버 · 말풍선 · 다시 보기 플레이어. **타일 · 카드 · 행 · 키에는 0개**.
2. 한 화면에 블러 판 **최대 2장**(머리글 + 떠 있는 판 하나). 블러 반경 머리글 20px, 판 24px — 더 키우지 않아요.
3. 블러 판 면적: 휴대폰은 탭 줄(약 390×50)만 붙어 떠요(시계 · 진행 막대 줄은 위로 올라가요, `top: -탭 위치`). 시트는 화면 아래 78% 이하.
4. 판 아래 지도가 움직이지 않게: 시트 · 툴팁이 떠 있는 동안 지도는 스크롤되지 않아요(지금 동작). 비용이 드는 건 **스크롤 중인 지도 위의 붙어 뜬 머리글**뿐.
5. 대체: 블러 미지원 · 투명도 줄이기 · 저전력(구현 때 `navigator.getBattery`가 아니라 측정된 프레임 시간이 연속 느리면) → 불투명 판(§6-2).
6. 움직이는 반사광은 화려하게에서 떠 있는 판 하나만, rAF 한 번에 CSS 변수 두 개.

**측정 (샌드박스 추정 — 실기기 아님)**: 390×844, DPR 2, CPU 4배 느리게, 지도 597타일(코스피 300 + 코스닥 300), 휴대폰 프레임을 rAF마다 12px씩 스크롤(295프레임). 이 헤드리스 크롬은 GPU가 없어 합성을 CPU가 해요 → 실기기보다 블러가 훨씬 비싸게 나와요. 상대 비교로만 보세요.

| 테마 (지금 시안: 머리글 = 가장자리에서 떨어진 유리 판) | 프레임 시간 중앙값 | 95% | 20ms 넘은 프레임 (두 번 잰 값) |
|---|---|---|---|
| 기본 | 16.7ms | 16.8~33.2ms | 12 · 16 / 295 |
| 신문 B | 16.7ms | 16.8ms | 12 · 10 / 295 |
| 글라스 A (머리글 붙어 뜸 + 블러) | 16.7ms | 50ms | **95 · 101 / 295** |
| 글라스 A, 블러 끔(대체 모습) | 16.7ms | 16.8~33.3ms | 22 · 10 / 295 |
| 글라스 B | 16.7ms | 33.4~49.9ms | 48 · 78 / 295 |

처음 시안(머리글 전체 폭 직사각형 유리)에서는 글라스 A 중앙값 33.3ms · 20ms 넘은 프레임 220/295, 블러 반경을 10px로 줄여도 224/295로 거의 같았어요(반경보다 "움직이는 지도 위에 블러 층이 있다"는 것 자체가 비용). 머리글을 안 붙이면 141/295 — 이 값은 다른 프레임의 유리 판이 같이 보였던 탓이 섞여 있어요. 측정값이 돌릴 때마다 꽤 흔들려요(샌드박스).

CPU 그대로(느리게 안 함)에서는 다섯 테마 모두 중앙값 16.7ms(60fps). 결론: **휴대폰에서 "스크롤되는 지도 위에 붙어 뜨는 유리 머리글"이 유일하게 큰 비용**이에요(느린 프레임이 기본의 약 6~8배, 대체 모습이면 기본 수준). 권장: 데스크톱만 붙어 뜨고(지도가 화면에 거의 다 들어와 스크롤이 적어요), 휴대폰은 머리글이 지금처럼 올라가고 유리는 떠 있는 판에만 — 결정 필요(보고서 질문 3). 실기기(안드로이드 크롬, 사용자 기기) 측정은 **확인 못 함**.

## 10. 접근성

- 대비 §8. 포커스 고리는 모든 테마 3px / 2px(controls.md §7), 색만 테마별(먹 · 앰버 · 짙은 앰버) — 바탕 대비 4.7~17.6.
- 색만으로 말하지 않아요: 등락은 부호 + 숫자, 완료 ✓ · 실패 ! + 글자, 고른 칸은 표시 상자(+ 먹 뒤집기), 열린 키는 걸린 모양 + 아이콘 색. 신문 B 섹터 머리는 숫자를 종이색으로 칠하고 부호로 말해요.
- 움직임 줄이기(기기 설정 → 시안 시작값 `줄이기`): 클릭 뒤 진행 중 애니메이션 0, 표시 전환 0s, 시장 띠 멈춤(측정). 유리 반사광 움직임 없음.
- 투명도 줄이기(`prefers-reduced-transparency`): 유리 → 불투명 판.
- 강제 색(`forced-colors`) · 200% 확대 · 스크린 리더 낭독: 시안에서 **확인 못 함**(구현 단계 점검 항목).
- 테마 선택 자체: `표시 설정 › 화면 › 테마` 세그먼트(`role="group"`, `aria-pressed`), 기기 다크/라이트 설정을 따라가는 "자동"은 이번 범위 밖(구현 때 따로 제안).

## 12. 구현 메모 (승인 뒤)

- **토큰 자리**: `src/template.html :root`는 기본 값 그대로, 그 아래 `html[data-theme="paper"]`, `html[data-theme="glass"]` 묶음(고른 변주의 값). 시안의 `.site[data-theme=…]` 규칙을 그대로 옮기면 돼요. 테마별 구조 규칙(카드 위 먹줄, 섹터 머리, 망점, 유리 `::after`)은 테마 선택자로 몇 줄씩.
- **상태**: localStorage `khm.theme`(`base|paper|glass`), `KH.theme()` + 이벤트 `kh:theme {theme}`(효과 설정 `kh:motion`과 같은 방식). 처음 그리기 전에 `<html data-theme>`를 정해 깜박임이 없게(머리 `<script>` 한 줄).
- **팔레트**: `PALETTES`를 테마별로(`PALETTES[theme][key]`) — `KH.palette()`가 지금 테마의 `stops/upText/dnText`를 돌려주면 extras(이미지 저장 · 시장 띠) · 종목 페이지 · 해외(세계지도 칠하기)가 그대로 따라와요. 타일 글자 색은 `--lab-mode`(halo|auto)로 템플릿이 정해요.
- **캔버스 · SVG로 그리는 곳**(이미지 저장, 종목 차트, 세계지도, 진행 막대, 시계)은 색을 CSS 변수에서 읽게(지금 하드코딩된 `#000`, `#131418` 등을 찾아 토큰으로). 영향 범위는 구현 시작 때 grep으로 목록을 만들어 보고해요.
- **시세 플래시**: 밝은 테마에서 지금의 흰/검정 덮개 플래시는 안 보여요 → `standard` 플래시도 `--up-text/--dn-text` 고리로(화려하게와 같은 모양).
- 순서 제안: ① 템플릿 토큰 + 설정 줄 + 지도 · 옆 카드 → ② extras(시계 · 진행 막대 · 시장 띠 · 이미지 저장) → ③ 종목 페이지 → ④ 해외 · 원자재(목록 · 세계지도). 단계마다 스크린샷 · 대비 · 지도 위치 측정.
- 표(표 보기) · 해외 목록 같은 촘촘한 표는 신문에서 행 점선 + 머리 아래 2px 먹줄, 글라스에서 블러 없는 유리 행.
