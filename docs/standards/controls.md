## 0. 한 줄 규칙

컨트롤은 **제자리에서** 살아 움직여요. 누르면 1px 가라앉고, 일하는 동안 같은 상자 안에서 글자가 고리로, 끝나면 체크로 바뀌어요. 길이는 **180 · 320 · 560ms**, 곡선은 **out · in · inout**, 튀는 건 **완료 체크뿐**(화려하게)이에요. 상태가 바뀌어도 **크기와 자리는 그대로**예요. 빨강 · 초록은 등락에만 쓰니까 완료와 실패는 **앰버 + 아이콘 + 글자**로 말해요.

## 2. 모션 토큰

`src/template.html :root`에 두고 JS는 `getComputedStyle`로 읽어요(지금의 `MT`처럼 한 곳에서). 데이터 모션 토큰 `--m-1/2/3`(120 · 240 · 480)은 그대로 두고, 컨트롤은 아래 `--c-*`만 써요.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--c-fast` | 180ms | 누름에서 올라옴, 글자 나감/들어옴, 칩 채움, 세그먼트 앞 가장자리, 글자색 |
| `--c-base` | 320ms | 세그먼트 뒤 가장자리, 체크 선 그리기, 비동기 바탕색, 꺾쇠 · 아이콘 모양 바꿈, 숫자 굴림 |
| `--c-slow` | 560ms | 머무는 시간의 단위 |
| `--c-switch` | 252ms (= fast × 1.4) | 스위치 손잡이 + 채움 |
| `--c-spin` | 840ms (= slow × 1.5) | 고리 한 바퀴(일정한 속도) |
| `--c-dwell` | 1120ms (= slow × 2) | "됐어요"가 머무는 시간, 말풍선 |
| `--c-arm` | 4000ms | 두 번 누름의 기다림 |
| `--c-out` | `cubic-bezier(.22,1,.36,1)` | 들어오는 것 · 도착하는 것 (기본) |
| `--c-in` | `cubic-bezier(.4,0,1,1)` | 나가는 것 |
| `--c-inout` | `cubic-bezier(.65,0,.35,1)` | 모양이 바뀌는 것(스위치, 꺾쇠, 아이콘 모양) |
| `--c-pop` | `cubic-bezier(.34,1.3,.64,1)` | **완료 체크 아이콘의 크기 .6→1에만** (화려하게) |

- 새 길이를 만들지 않아요. 더 긴 시간이 필요하면 `--c-slow`의 배수로.
- 누름은 **내려갈 때 0ms**(손가락과 같이), 올라올 때 `--c-fast --c-out`. 누름에 `--c-pop`을 쓰지 않아요(튕기지 않음).

## 3. 효과 단계 매핑 (`KH.motion()` · `html[data-motion]`)

| 움직임 | 줄이기 `reduced` | 기본 `standard` (기본값) | 화려하게 `fancy` |
|---|---|---|---|
| 누름 1px + 그림자 + 어두워짐 | 끝 상태만(바로 가라앉고 바로 올라옴) | ✓ | ✓ |
| 세그먼트 · 탭 표시 이동(앞 fast · 뒤 base) | 바로 그 칸 | ✓ | ✓ |
| 글자 바꿈(위로 나감 · 아래에서 들어옴) | 바로 바뀜 | ✓ | ✓ |
| 체크 선 그리기, 칩 체크 자람, 스위치 252ms, 꺾쇠 · 아이콘 모양 | 바로 | ✓ | ✓ |
| 하는 중 고리 | **멈춘 고리**(모양은 보여요) | 일정하게 돌아요 | + 호 길이가 천천히 늘고 줄어요 |
| 완료 체크 pop(.6→1, `--c-pop`) | — | — | ✓ |
| 숫자 굴림(탭 등락률, 종목 수, 다시 보기 시각, 그룹 수) | 바로 바뀜 | 바로 바뀜 | ✓ |
| 펼친 줄 등장(opacity + 4px, 20ms 간격) | — | — | ✓ |
| 포커스 고리 | 바로 | 바로 | 바로 (어느 단계든 애니메이션 없음) |

- `reduced`는 CSS에서 `[data-motion="reduced"] *{transition-duration:0s!important;transition-delay:0s!important;animation:none!important}`로 한 번에. 상태(하는 중 · 됐어요 · 안 됐어요)는 **모두 그대로 보여요** — 움직임만 없어요.
- 진행 중인 것은 `kh:motion`이 내려가면 `finish()`로 끝 상태로(motion-brief §3과 같음).

## 4. 표면 토큰 — V1 입체 (승인)

레퍼런스의 깊은 표면 그대로예요: 키와 고른 칸은 솟아서 그림자를 떨구고, 트레이와 트랙은 깊게 파여요. 이름은 역할로 붙이고 컨트롤 CSS는 이 토큰만 써요(`src/template.html :root`).

| 역할 토큰 | 값 |
|---|---|
| `--tray-bg` / `--tray-sh` (파임: 세그먼트 트레이, 스위치 트랙, 검색 칸) | `#0f1014` / `inset 0 1px 3px rgba(0,0,0,.7), inset 0 0 0 1px rgba(255,255,255,.05)` |
| `--ind-bg` / `--ind-sh` (고른 칸 표시) | `#2c2f37` / `inset 0 1px 0 rgba(255,255,255,.13), 0 1px 2px rgba(0,0,0,.55), 0 4px 10px rgba(0,0,0,.35)` |
| `--key-bg` · `--key-fg` · `--key-ic` / `--key-sh` (솟음) | `#25272e` · `--fg` · `--fg2` / `inset 0 1px 0 rgba(255,255,255,.12), 0 1px 2px rgba(0,0,0,.55), 0 4px 10px rgba(0,0,0,.3)` |
| `--key-dn` (눌림) | `inset 0 1px 2px rgba(0,0,0,.55)` |
| `--key-on` (열림 · 걸림: `aria-expanded`) | `inset 0 1px 3px rgba(0,0,0,.6), inset 0 0 0 1px rgba(255,181,71,.5)` + 앰버 글자 · 아이콘 |
| `--pri-bg` / `--pri-fg` / `--pri-sh` (주 버튼) | `#eef0f3` / `#131418` / `inset 0 1px 0 rgba(255,255,255,.7), 0 1px 2px rgba(0,0,0,.55), 0 4px 10px rgba(0,0,0,.3)` |
| `--press-f` | `brightness(.86)` |
| 됐어요 `--done-bg` / `--done-fg` | 앰버 채움 / `#1b1404` + 체크 |
| 안 됐어요 `--fail-bg` / `--fail-fg` / `--fail-ring` | `#2d2519` / `#ffd8a1` / 앰버 α .6 + 앰버 `!` |
| 칩 `--chip-bg` / `--chip-on` / `--chip-ring` | `#25272e` / 앰버 20%를 섞은 `#25272e` / 앰버 α .8 |
| 스위치 `--trk` / `--knob` / `--knob-sh` / `--knob-dn` | `#0f1014` / `#f3f4f7` / `0 1px 1px rgba(0,0,0,.3), 0 3px 6px rgba(0,0,0,.45), inset 0 1px 0 rgba(255,255,255,.85)` / 아래 그림자 2px |

- 그림자는 컨트롤 바깥으로 최대 10px(`0 4px 10px`). 지도 위로 겹치는 팝오버 · 시트의 그림자는 지금 값 그대로예요.
- 테두리(`border`)는 쓰지 않고 테는 `inset` 그림자로 그려요. 지금 테두리 1px만큼은 안쪽 여백을 1px 늘려 **상자 크기를 그대로** 둬요(지도 위치가 바뀌지 않게).
- 앰버는 "고름 · 열림 · 포커스 · 완료"에만. 실패를 빨강으로, 완료를 초록으로 칠하지 않아요(등락과 헷갈려요). 색만으로 구분하지 않고 **아이콘(✓ · !) + 글자**가 늘 같이 있어요.
- (버린 안 V2 "지도 우선"의 얕은 값은 `drafts/controls.html`에 기록으로만 남아요.)

## 5. 컨트롤별 규칙

### 5-1. 누름 (키 · 주 버튼 · 칩 · 아이콘 키 · 시계)
- 누름: `transform: translateY(1px)` + `box-shadow: var(--key-dn)` + `filter: var(--press-f)`, **0ms**. 뗌: 같은 값이 `--c-fast --c-out`으로 돌아와요.
- 키보드: Space · Enter를 누르고 있는 동안 같은 모양(`.is-press`), 떼거나 포커스가 나가면 풀려요.
- Android Chrome에서 `:active`가 손가락에 바로 붙도록 `document`에 빈 `touchstart`(passive) 하나.
- 세그먼트 · 탭의 칸, 메뉴 항목, 목록 줄은 가라앉지 않고 `filter`만(줄 · 칸 전체가 1px 움직이면 표 · 목록이 흔들려 보여요).
- 테두리 없는 아이콘 키(☆, ×, ↑↓, 시계)는 그림자 없이 1px + `filter`만.
- 꺼진 것 · 하는 중(`aria-busy="true"`) · `aria-disabled`는 눌리지 않아요.

### 5-2. 키 · 주 버튼
- 키: `--key-bg/--key-sh`, 높이 데스크톱 34 · 휴대폰 40(지금 그대로). 아이콘 16px `--key-ic`.
- 열림 · 걸림(`aria-expanded="true"` — 표시 설정, 화면 ⚙, 리플레이, 색 기준 ▾): **눌린 채 걸린** 모양 `--key-on` + 앰버 아이콘 · 글자. 가라앉지는 않아요(옆 키와 1px 어긋나지 않게).
- 주 버튼(차트·호가 보기, 만들기, 완료): `--pri-bg`. 한 화면에 하나.
- `▾` 달린 키(색 기준, 통합 ▾)는 열리면 꺾쇠가 반 바퀴(`--c-base --c-inout`), 고른 값이 바뀌면 키 글자가 §5-3 글자 바꿈으로.

### 5-3. 비동기 버튼 (보통 → 하는 중 → 됐어요 / 안 됐어요)
- **글자 상자**: 상태별 글자를 한 칸(grid `1/1`)에 겹쳐 두고 지금 것만 보여요 → 상자 폭은 **가장 긴 글자 폭으로 고정**, 옆 컨트롤이 움직이지 않아요(레퍼런스의 "폭이 글자를 따라감"은 쓰지 않아요). 가장 긴 글자가 너무 길면 문구를 줄여요.
- 글자 바꿈: 나가는 글자 `opacity 1→0` + `translateY(0→−6px)` `--c-fast --c-in`, 들어오는 글자 `6px→0` `--c-fast --c-out`을 `--c-fast` 뒤에.
- 하는 중: 고리(16px, `currentColor`) + 글자, `aria-busy="true"`, 다시 눌리지 않아요, 흐려지지 않아요. 고리 한 바퀴 `--c-spin` 일정하게.
- 됐어요: §4의 됐어요 표면 + 체크 선(`stroke-dashoffset 22→0`, `--c-base --c-out`, `--c-fast` 뒤) · 화려하게면 + 크기 `.6→1 --c-pop`. `--c-dwell` 머문 뒤 보통으로.
- 안 됐어요: §4의 안 됐어요 표면 + `!` + **까닭이나 다음 행동을 글자로**("실패 · 다시"). 흔들지 않아요. 누를 때까지 그대로(누르면 다시 시도).
- 화면 읽기: 바뀐 글자를 `aria-label`로, 결과는 공용 알림 영역(`aria-live="polite"`)에 한 번.
- **아이콘만 있는 키**(휴대폰 · 1600 미만의 이미지로 저장 · 리플레이): 아이콘이 같은 자리에서 바뀌고(그림 → 고리 → ✓ / !) 말은 키 아래 **말풍선**(절대 위치, 자리 차지 없음, 누르지 않음, `--c-dwell + --c-slow` 뒤 사라짐) + 알림 영역(`aria-live="polite"`). `aria-label`은 "이미지로 저장" 그대로. (사용자 결정 ③)
- 문구(해요체): 이미지로 저장 → 만드는 중 → 저장했어요 / 실패 · 다시 · 다음 60일 더 보기 → 불러오는 중 → 60일 더 불러왔어요 / 못 불러왔어요 · 다시 · 다시 시도 → 받는 중 → 받았어요 / 아직 안 돼요 · 다시.
- 세그먼트 안의 비동기(종목 수 **전체**): 표시는 바로 그 칸으로 가고, 받는 동안 그 칸 글자 앞에 작은 고리(12px), 다 받으면 고리가 빠지고 지도 머리줄의 종목 수가 굴러가요(화려하게).
- 시계(새로고침): 숫자 오른쪽 14px 자리에 고리(절대 위치 — 시계 크기 그대로), 끝나면 시계 아래 말풍선 + 알림: ✓ "새 시세를 받았어요" / ! "못 받았어요 · 다시 눌러 주세요". 스냅샷은 아이콘 없이 "미리보기는 고정된 시세예요". (2단계에서 바뀜: 오케스트레이터 지시 2026-11-13 "busy, then done ✓ or fail !, via the bubble" — 처음 규칙은 체크 없이 실패만 알렸어요.)

### 5-4. 세그먼트 (하나 고르기)
- 트레이는 파이고(`--tray-sh`), 고른 칸 표시(`.ind`, 절대 위치 상자 하나)는 솟아요(`--ind-sh`). 글자색 `--muted → --fg`, `--c-fast`.
- 이동: **가는 쪽 가장자리가 `--c-fast`, 뒤 가장자리가 `--c-base`**(`--c-out`) → 늘었다 줄며 도착, 흔들림 없음. 위아래 줄이 바뀌면(2×2 색상) `top/bottom`도 `--c-base`.
- 자리는 `offsetLeft/offsetTop`으로 `--l --r --t --b`에, 크기가 바뀌면(ResizeObserver) 전환 없이 다시. 표시는 `left/right`로 움직이지만 다른 요소의 배치에는 영향이 없어요(절대 위치 상자 하나).
- 데스크톱 팝오버 목록(색 기준 · 순매수 기간 ≥1280)은 표시 대신 고른 줄에 앰버 글자 + 체크(선 그리기), 고르면 `--c-fast` 뒤 닫히고 포커스는 ▾ 키로.
- 꺼짐(지금 `.ctl.off`): 트레이 전체 `opacity .45`, 까닭은 힌트 글자로.
- 버튼 의미는 지금처럼 `aria-pressed`(그룹 `role="group"` + `aria-label`).

### 5-5. 시장 탭
- 세그먼트와 같은 표시 + 표시 아래쪽에 앰버 2px 막대(지금의 `inset 0 −2px 0` 밑줄이 표시와 같이 움직여요).
- 휴대폰: 탭 줄은 가로로 넘어가요. 표시는 스크롤 내용과 같이 움직이고, 고르면 그 탭이 보이게 `scrollIntoView({inline:'nearest'})`(줄이기면 바로).
- 탭 아래 등락률(§3-16)은 화려하게면 바뀐 자리만 굴러가요(§5-14). 줄 높이는 그대로.

### 5-6. 밑줄 탭 (종목 페이지 탭 · 공시 종류)
- 표시가 2px 앰버 막대예요. 이동 규칙은 세그먼트와 같아요(앞 fast · 뒤 base).

### 5-7. 칩
| 종류 | 어디 | 켜짐 | 움직임 |
|---|---|---|---|
| **고르기 칩**(하나만) | 관심 그룹, 뉴스·공시, 해외 상세의 같은 나라 지수 (티커 분류는 2단계에서 세그먼트로 — A-28) | 채움 `--chip-on` + 테 1.5px `--chip-ring` + 수는 앰버 | 채움 · 테 `--c-fast --c-out`. **체크 없음 → 폭이 그대로**라 옆 칩이 밀리지 않아요 |
| **켜고 끄기 칩**(여럿) | 티커 항목 "추가 ↔ 추가됨" | 채움 + 테 + 체크 | 체크 `width 0→14px` + opacity + scale .6→1 `--c-fast`. **줄 오른쪽 끝에 붙은 칩에만**(자라도 옆이 안 밀려요). 글자는 §5-3 글자 상자 |
| **가는 칩**(누르면 이동) | 종목 페이지 같은 업종 | — | 솟은 칩, 누르면 1px + `›`가 2px 나가요 |
| **메뉴 칩** | 휴대폰 가격 기준 `통합 ▾` | 열림 = `--key-on` | 꺾쇠 반 바퀴, 고른 값은 글자 바꿈 |
- 관심 그룹 칩과 `⋯`는 한 칩 몸통을 나눠 써요(켜짐 채움 · 테는 몸통 전체에).

### 5-8. 스위치 (`role="switch"`)
- 파인 트랙(`--tray-sh`) + 솟은 손잡이(`--knob-sh`, 빛은 위에서). 44 × 26, 손잡이 22, 길 18px. 줄 높이(데스크톱 36 · 휴대폰 44) 안에 들어가요.
- 켜기 · 끄기: 손잡이 `translateX` + 앰버 채움 `opacity`가 **같은 `--c-switch` · 같은 `--c-inout`**으로 끝까지.
- 누름: 손잡이 그림자만 짧아져요(`--knob-dn`). 크기 그대로, 가라앉지도 튕기지도 않아요. 줄 전체는 `filter`만.
- 끌기: 트랙을 3px 넘게 끌면 손잡이와 채움이 손가락을 따라오고(`touch-action: pan-y` — 시트 스크롤은 그대로), 놓으면 가까운 쪽으로 이어서 가요.
- 줄 전체가 버튼(지금 `.swbtn`처럼). 지금 두 모양(설정 34×20, 종목 페이지 32×18)을 하나로.

### 5-9. 아이콘 토글
- ☆ → ★: 채움 `fill` + 색 `--c-fast --c-out`. pop 없어요(완료가 아니에요). 그룹이 여럿이면 그룹 고르기가 열리고, 하나라도 체크면 ★.
- 그룹 고르기 체크 상자: 파인 18px 상자 → 앰버 채움 + 체크 선 그리기(`--c-base`).
- 티커 ⏸ ↔ ▶, 다시 보기 ▶ ↔ ⏸: 두 모양이 제자리에서 회전 · 크기 · opacity로 바뀌어요(`--c-base --c-inout`). `aria-pressed` / `aria-label` 같이 바뀌어요.
- 표 머리 정렬: 고른 열의 ▾가 방향이 바뀌면 반 바퀴(`--c-base --c-inout`), 다른 열로 옮기면 opacity.

### 5-10. 더보기 (30개) · 접기
- 글자 바꿈(§5-3) + 꺾쇠 반 바퀴. 폭은 고정(가장 긴 글자).
- 펼친 줄은 화려하게면 opacity + 4px, 20ms 간격(최대 8줄까지만 간격, 나머지는 함께). 높이 애니메이션은 하지 않아요(목록 아래가 미끄러지듯 밀리지 않게 한 번에).
- 휴대폰에서 접을 때 카드 머리로 스크롤 복귀(§3-14 그대로).

### 5-11. 두 번 누름 (되돌리기 어려운 일)
- 티커 항목 **기본값으로**: 첫 누름 → 안 됐어요 표면 + `!` "한 번 더 누르면 되돌려요" + 아래 3px 띠가 `--c-arm`(4초) 동안 일정하게 줄어요. 0.4초 안의 두 번째 누름은 받지 않아요(실수 연타). 4초가 지나면 보통으로. 두 번째 누름 → 됐어요(§5-3).
- 관심 그룹 지우기는 지금처럼 확인 창(빠질 종목 수를 알려 줘야 해서) — 창의 "지우기"만 주 버튼 규칙.

### 5-12. 꺼짐 · 잠김
- 꺼짐(`disabled`): `opacity .45`, 그림자 없음, 안 눌려요, 까닭은 `title`/힌트 글자("국내 지도 탭에서 쓸 수 있어요").
- 잠김(스냅샷에서 실시간 기능): 자물쇠 + 까닭 글자, **눌려요**(누르면 글자 바꿈으로 "실시간 주소로 열어요" + 링크).

### 5-13. 메뉴 · 팝오버 항목
- 고른 항목: 앰버 글자 + 오른쪽 체크(선 그리기). 높이 데스크톱 36 · 휴대폰 44~54.
- 열면 고른 항목에 포커스, Esc · 바깥 누름으로 닫히고 포커스는 연 키로. 고르면 `--c-fast` 보여 준 뒤 닫혀요.
- 팝오버 · 시트가 열리는 움직임은 motion-brief (g) 그대로.

### 5-14. 숫자 굴림 (화려하게만)
- 바뀐 자리만 `translateY(±100%)` + opacity, `--c-base --c-out`, 오른쪽 자리부터 40ms씩. 늘면 위로(새 숫자가 아래에서), 줄면 아래로.
- 자리 수 · 부호가 바뀌면 굴리지 않고 `--c-fast` 교차. 색(등락)은 바뀐 순간 새 색. 접근성 이름은 전체 값.
- 쓰는 곳: 탭 등락률, 지도 머리줄 종목 수 · 등락률, 관심 그룹 수, 다시 보기 시각. 시장 띠 · 종목 페이지 현재가는 지금 오도미터(motion-brief b) 그대로 — 구현 때 한 함수로 합쳐요.

### 5-15. 입력 (검색 · 그룹 이름 · 날짜 · 슬라이더)
- 파인 칸(`--tray-sh`). 포커스는 §7과 같은 모양을 `box-shadow`로(`0 0 0 2px --page, 0 0 0 5px --amber`) — 둥근 모서리를 따라가요.
- 다시 보기 슬라이더 손잡이는 스위치 손잡이와 같은 표면, 끄는 동안 `--knob-dn`.

## 6. 누름 영역 44px

- 보이는 크기는 지금 그대로(데스크톱 키 34, 휴대폰 40), 누르는 곳만 `::after`로 44 × 44 이상(`@media (pointer:coarse)`에서만).
- 이웃한 두 작은 컨트롤의 누름 영역이 겹치지 않게: 34px 키끼리는 10px 이상, 40px 키끼리는 4px 이상 띄워요(시안 측정: 붙은 키는 영역이 빈틈없이 맞닿아요).
- **스크롤 상자 안**(휴대폰 탭 줄, 칩 줄)은 `::after`가 잘려요 → 상자에 위아래 여백(패딩 2px + 같은 크기 음수 마진)을 줘서 자리는 그대로, 누름 영역만 살려요.
- AGENTS §5 "모바일 탭 영역 40px 이상"은 보이는 크기 기준으로 그대로 지켜요.

## 7. 포커스

- `:focus-visible { outline: 3px solid var(--amber); outline-offset: 2px }`, 전환 없이 바로.
- 잘리는 상자 안(가로 스크롤 탭 · 칩 줄, 표 머리, 메뉴 항목, 지도 타일)은 `outline-offset: -3px`(안쪽).
- 세그먼트 칸은 `-1px`(트레이 여백 3px 안에 들어가요). 둥근 입력은 §5-15.
- 시트 · 팝오버 · 종목 페이지는 Esc로 닫히고 연 컨트롤로 포커스가 돌아가요(§5 품질 기준 그대로).

## 8. 움직이지 않는 것 (레이아웃 안정성)

- **상태가 바뀌어도 컨트롤의 크기 · 자리는 그대로**: 글자 상자는 가장 긴 글자 폭, 아이콘 키는 아이콘만, 고르기 칩은 체크 없이, 체크가 자라는 칩은 줄 끝에서만.
- **지도 위치(map top)는 컨트롤 상태로 바뀌지 않아요**: 탭 · 가격 기준 · 시계 새로고침 · 저장 · 표시 설정 · 종목 수 전체 · 색 범위 · 색상 · ⚙ · 지도/표 모두 0px(시안에서 측정, §12). (★관심 탭의 그룹 칩 줄은 원래 그 탭의 배치예요 — 컨트롤 상태가 아니에요.)
- 누름의 1px는 `transform`이라 배치에 영향이 없어요. 걸린 키(`aria-expanded`)는 가라앉지 않아요.
- 말풍선 · 메뉴 · 팝오버는 절대 위치(자리 차지 없음).
- 데이터 표시(타일 · 막대 · 표 행 · 숫자)는 누를 때 가라앉거나 커지지 않아요.

## 9. 접근성 · 문구

- 상태 바뀜: `aria-busy`(하는 중), `aria-pressed`/`aria-checked`/`aria-expanded`, 글자 상자는 지금 글자를 `aria-label`로. 결과 문구는 알림 영역 하나(지금 extras의 토스트 영역을 재사용 가능)에.
- 색만으로 구분하지 않아요: 완료 ✓, 실패 !, 잠김 자물쇠, 켜짐 체크 또는 테.
- 문구는 해요체, 짧게, 다음 행동을 말해요("실패 · 다시", "한 번 더 누르면 되돌려요"). 영문 대문자 장식 없음.
- 대비(계산값): 앰버 글자 #ffb547 / `--panel` 9.9:1 · `--page` 10.5:1, V1 됐어요 #1b1404 / 앰버 10.4:1, V1 실패 #ffd8a1 / #2d2519 11.2:1, 고르지 않은 칸 `--muted` / `--panel` 5.4:1 · V1 트레이 5.9:1, V1 주 버튼 16.1:1.

## 10. 성능

- 움직이는 속성은 `transform` · `opacity` · `filter` · `box-shadow`(작은 컨트롤) · 세그먼트 표시의 `left/right/top/bottom`(절대 위치 상자 하나)만.
- 무한 애니메이션은 하는 중 고리뿐(하는 동안만). 숨은 탭에서는 멈춰요.
- 숫자 굴림은 바뀐 자리만, 화면에 보이는 것만(시장 띠는 지금 규칙).
- 그림자 반경 최대 10px — 누를 때 다시 칠하는 면적이 작은 컨트롤 하나 크기라 가벼워요(실기기 확인은 못 했어요).

## 11. 구현 메모 (승인 뒤, 모듈별)

- 템플릿(`src/template.html`, 히트맵 담당)이 토큰(`--c-*`, §4 표면 토큰), 공용 CSS와 공용 함수 `KH.ui`를 내보내요(1단계에 들어갔어요 — 목록은 §11-1). 다른 모듈(extras · stock · world)은 있으면 쓰고 없으면 지금 동작.
- 순서(사용자 결정 ④): ① 템플릿 머리글 · 도구 줄 · 표시 설정 · 지도 머리줄 · 옆 카드 → ② extras(저장 · 리플레이 · 티커 · 티커 고르기 · 시계 · 진행 막대) → ③ 종목 페이지 → ④ 해외 · 원자재. 단계마다 지도 위치 · 넘침 · 포커스 측정, 스크린샷 확인, 커밋.
- 정리할 불일치(목록 부록 A의 ⚠): 티커 고르기의 파랑 강조(`#8ab4ff`)와 흰 바탕 분류 칩 → 앰버 규칙으로, 스위치 두 모양 → 하나로, 고른 칸 표시 두 방식(안쪽 테 / 앰버 밑줄) → 세그먼트 = 표시, 탭 = 표시 + 앰버 막대, 관심 그룹 고르기 두 구현(히트맵 `wgpop` · 종목 페이지 `sp-gp`) → 같은 모양 · 같은 체크.

### 11-1. 1단계(템플릿)에 들어간 공용 부품 — 다른 모듈은 있으면 써요

- **토큰**: `:root`의 `--c-*`(길이 · 곡선), `--focus-w/off`, §4 표면 토큰(`--tray-*`, `--ind-*`, `--key-*`, `--pri-*`, `--done-*`, `--fail-*`, `--r-*`, `--trk`, `--knob*`, `--chip-*`), `--ck-mask`(체크 모양 마스크). `html[data-motion="reduced"]`는 `--c-fast/base/switch`를 0ms로 바꿔요 → 토큰을 쓰는 전환은 따로 끄지 않아도 바로 끝 상태예요(머무는 시간 `--c-slow/dwell`은 그대로).
- **CSS**: `.seg`/`.tabs`/`.movers-tabs`의 `::before` 표시(+ `.tabs::after` 앰버 막대), `[data-dir]` 앞·뒤 가장자리 전환, `--ind-in`(트레이 여백이 없는 세그먼트의 표시 들여쓰기), `.is-press`(키보드 누름), `.kspn`(고리), `.klb/.kl`(글자 상자) + `.kck`(체크 선) · `.kwn`(!), `.sw-go/.sw-n`(글자 바꿈), `.rc/.rs`(숫자 굴림), `.kbub`(말풍선), `.kov`(칸 안 고리).
- **`KH.ui`**:
  - `seg(el)` — 세그먼트 · 탭 줄을 등록해요. `aria-pressed`가 바뀌면 표시가 움직이고(앞 fast · 뒤 base), 크기가 바뀌면 바로 그 자리에. 버튼은 `el`의 직계 자식 `<button aria-pressed>`.
  - `swap(el, text, from?)` — 글자를 같은 자리에서 바꿔요(나감 위로 · 들어옴 아래에서). `el.textContent`는 늘 새 글자.
  - `roll(el, text, dir)` — 화려하게면 바뀐 숫자 자리만 굴러요(`dir` +1 늘면 위로, −1 줄면 아래로). `el.textContent`는 늘 새 값이라 읽는 코드가 깨지지 않아요.
  - `busy(btn, promise)` — 끝날 때까지 `aria-busy` + 칸 안 고리(세그먼트 칸은 글자 대신 고리, 폭 그대로).
  - `state(el, st)` — `.klb > .kl[data-l~="st"]` 글자 상자의 상태를 바꿔요(`data-busy="work"`면 `aria-busy`, 버튼이면 `aria-label`도). 비동기 버튼(이미지로 저장 등)에 써요.
  - `bubble(anchor, text, 'done'|'fail')` — 아이콘만 있는 키 아래 말풍선(1.68초, 자리 차지 없음) + 알림.
  - `sw(btn)` — `.swbtn`(줄 버튼 + `.swt` 트랙) 스위치를 끌 수 있게.
  - `live(text)` · `icon('check'|'warn'|'spin')` · `ms('--c-base')`.
- 1단계에서 템플릿에 적용한 곳: 시장 탭(표시 + 앰버 막대, 화려하게면 등락률 굴림) · 가격 기준(세그먼트 · 휴대폰 칩 + 메뉴 체크) · 도구 줄 키(표시 설정 · 화면 · ▾) · 모든 `.seg`(크기 · 색 기준 · 순매수 기간 · 종목 수[전체 받는 동안 고리] · 색 범위 · 색상 · 효과 · 관심 탭 등락률 · 설정 선택지 · 지도/표) · 설정 스위치(끌기) · 검색 칸 · 관심 그룹 칩 · ⋯ · ＋ · 그룹 팝오버(체크 상자 · 버튼 · 이름 칸) · 빈 지도 안내 버튼 · ‹ 상위로 · 섹터 · 종목 정렬 탭 · 더보기/접기 · 빠른 시트(×, ☆, 버튼) · 표 ☆ · 타일 ☆ · 포커스 3px.

### 11-2. 2단계(extras)에 적용한 곳 — 새 토큰 · 새 공용 함수 없이 템플릿 것만 써요

- **도구 줄 키**(`.xt-btn`: 이미지로 저장 · 리플레이 · 앱으로 설치): 솟은 키 + 1px 누름, 리플레이 열림 = `--key-on`, 해외 탭에서 꺼짐(`aria-disabled`, opacity .45). 이미지로 저장은 비동기 키(§5-3): 아이콘 칸에서 그림 → 고리 → ✓ / !, 글자 상자(1600px 이상)도 같이 바뀌고, 아이콘만 보일 때는 결과를 말풍선(`KH.ui.bubble`)으로. 까닭(지도 보기에서 저장할 수 있어요 · 지도 탭에서만 저장할 수 있어요)도 말풍선. 토스트는 `KH.ui`가 없을 때만 쓰는 예비.
- **시계 새로고침**: 고리(절대 위치) → 말풍선 ✓ / ! (§5-3 시계 줄).
- **다시 보기 플레이어**: ▶ ↔ ⏸ 제자리 모양 바꿈(§5-9), 속도 = `.seg`(`KH.ui.seg`), 날짜 = 파인 칸 + 그림자 고리(§5-15), 슬라이더 손잡이 = 스위치 손잡이(`--knob`, 누르는 동안 `--knob-dn`), ⋯ · 다시 시도 = 솟은 키, × = 테두리 없는 키, 시각 숫자는 ←/→와 느린 재생(장면 0.4초 이상)에서만 굴러요(화려하게, `KH.ui.roll`).
- **티커**: 항목 = 테두리 없는 키(1px + 어두워짐, Enter/Space도), 끌면 눌림이 풀리고 흐름을 손가락으로 감아요, 튕기면 `--c-slow` 동안 미끄러져 멈춰요(줄이기면 바로 멈춤), 다시 흐를 때 `--c-slow`에 걸쳐 속도가 붙어요. ⏸ ↔ ▶ = 솟은 둥근 키, 멈춤 = `--key-on` + 앰버 아이콘.
- **티커 항목 고르기**: 분류 = 세그먼트(A-28), 추가 ↔ 추가됨 = 켜고 끄기 칩(§5-7, 줄을 다시 그리지 않고 제자리에서), ↑ ↓ ✕ = 테두리 없는 키(SVG 화살표, 끝에서 꺼짐 .45), 기본값으로 = 두 번 누름(§5-11, 기본 구성일 때는 꺼짐), 완료 = 주 버튼, 종목 검색 = 파인 칸.
- **작은 창**(티커 정보 · 저장 미리보기 · 홈 화면에 추가): × = 테두리 없는 키 + 44px, 네이버 증권에서 보기 · 고르기 = 솟은 키.
- **진행 막대**: 포커스 고리 3px / 2px, 말풍선은 `.kbub`와 같은 모양 · 움직임(토큰), Esc로 닫혀요, 화면 읽기에는 막대의 `aria-valuetext`만(말풍선 글자는 1분마다 다시 읽히지 않게 숨김). 알약 · 배치는 그대로.
- 움직임 줄이기: 모두 `--c-*` 토큰이라 `html[data-motion="reduced"]`면 끝 상태로 바로. extras.css의 `prefers-reduced-motion` 중 컨트롤 것은 `html[data-motion]`으로 바꿨어요(티커 흐름 · 진행 막대 장식은 그대로).
